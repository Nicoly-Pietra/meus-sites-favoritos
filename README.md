# 🌐 Meus Sites Favoritos

## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade do curso Técnico em Desenvolvimento de Sistemas do CPS.

O objetivo é criar uma página web para reunir cinco sites favoritos, apresentando imagens, nomes e links para acessar cada site.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3

## ⭐ Sites favoritos

1. Google – https://www.google.com
2. YouTube – https://www.youtube.com
3. Instagram – https://www.instagram.com
4. GitHub – https://github.com
5. Canva – https://www.canva.com

## 🎯 Funcionalidades

- Exibição de cinco sites favoritos.
- Imagens representativas de cada site.
- Links para acessar os sites.
- Layout organizado e responsivo.
- Efeitos visuais nos links.

## 📂 Arquivos do projeto

- `index.html` – Código-fonte da página.
- `print-codigo.png` – Captura de tela do código.
- `print-pagina.png` – Captura de tela da página executada.
